# 洛天依聊天

一个装在自己手机上的洛天依聊天工具。原生 Kotlin 外壳 + WebView 界面，没有用任何框架。

## 能干什么

- 聊天。人设是洛天依，语气、小动作、表情包、记忆都配好了。
- 换模型。DeepSeek、OpenAI、Kimi、通义千问、智谱都能接，也能填自定义地址。每个服务商各存一份 Key。
- 联网。DeepSeek 走官方搜索接口；别家可以填一个 DeepSeek Key 当中继，或者退回 Bing。
- 听歌。内置网易云，能搜、能播、有歌词、能登自己的账号。
- 记账。余额按小笼包算，每轮花了多少右上角会飘一下。
- 记忆。聊着聊着她会自己记，也能手动加、改、删，还能整理合并。

## 怎么装

release 文件夹里的 apk，点开装就行（覆盖安装不需要卸载）。

第一次打开：右上角齿轮 → 选服务商 → 填 Key → 点「测试连接」。
看到「回答：我是…」就说明通了，回聊天页直接说话。

## 两个开关值得知道

- 搜索中继：如果你主用千问这类没有搜索接口的模型，在设置里填一个 DeepSeek Key 当中继，搜索就能继续用。
- 调试模式：默认关。开了之后才会往 Download 写日志，出问题再开。

## 关于隐私

Key 和网易云登录信息都只在你手机本地，不会跟着 apk 走，也不会进这个仓库。

## 目录

- app/src/main/ ：源码、页面、立绘、表情
- release/ ：装好的 apk
- build.sh、tools/ ：本机构建用的脚本，普通开发用 Android Studio 打开 app/ 就行
